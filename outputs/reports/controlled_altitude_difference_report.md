# 受控合成轨道高度差风险正式实验报告

## 1. 实验边界与规模

本实验保持合法 A 的真实 Starlink TLE 和 A 定义的 pass 不变；B 是由 A 的 mid-pass 状态构造的同轨道面圆轨道近似，不是真实 Starlink 攻击轨道。高度变化通过半径与开普勒角速度共同变化实现。正式 verifier、score/b/k/coverage 门限和 final decision 均未修改。

- target：5，ID=['44714', '65409', '65410', '65421', '65686']
- 每 target same-TLE pass：4
- signed nonzero delta_h：[-100.0, -50.0, -20.0, -10.0, -5.0, -2.0, -1.0, 1.0, 2.0, 5.0, 10.0, 20.0, 50.0, 100.0]
- 额外 reference：delta_h=0；不进入非目标风险
- 每 target×pass×height：重新计算8方向，选择 lowest/opposite/high
- 每 geometry realization：20
- 独立 observation：18000
- mode rows：54000；current_bk 为正式主口径

## 2. 数据有效性

## 8. 对研究问题的事实回答

1. **高度差总体改变局部几何可分性。** 在 840 个非零 current geometry 上，`|delta_h|` 与 raw geometry RMSE、post-b/k geometry RMSE、方向敏感度的 Spearman 分别为 `0.876/0.871/0.871`。三个方向角色内也保持强正相关；这说明在本受控圆轨道构造和已选 pass 中，绝对高度差增大通常会扩大局部差分多普勒几何量，但不能外推为普遍因果律。
2. **总体风险随 `|delta_h|` 增大而下降，但不是统一安全边界。** 10°有效、current_bk 的 pooled accept fraction 从 `|delta_h|=1 km` 的 `0.8646` 依次下降到 `2/5/10/20/50/100 km` 的 `0.8404/0.8242/0.7213/0.5258/0.2913/0.0996`；geometry-level Spearman 为 `-0.695`。该序列在本实验网格上单调，但 pass/direction 条件值并不统一。
3. **pass 和 direction 影响显著。** lowest/opposite/high 的平均条件接受比例为 `0.672/0.681/0.433`；对应 median raw geometry RMSE 为 `3.53/3.58/18.30 Hz`。在 `delta_h=100 km` 时，20 个 target-pass 的 pooled-direction 接受比例仍覆盖 `0–0.60`；说明相同高度差在不同 pass 中并不产生固定风险状态。
4. **k gate 是主要门限机制，但不是唯一机制。** 16,800 个正式 current realization 中，k/b/score failure 分别为 `5450/1037/1607`（可重叠）；单一 primary failure 中 k/b/score 为 `4328/482/828`，另有 `1161` 个多 gate failure。current→wide 新增 `2856` 个接受，其中 `2256` 为仅 k gate 解除、`482` 为仅 b gate 解除、`118` 为 b/k 同时解除；k 参与 `83.1%` 的新增接受。
5. **较大非零高度仍存在局部低可分性。** `+100 km` 的 lowest/opposite 平均接受比例仍为 `0.210/0.243`，各有条件达到 `0.95`；`-100 km` 对应均值为 `0.075/0.070`，high-sensitivity control 在正负 100 km 均为 0。这里的 0/20 不称为安全，非零接受也只代表特定 target×pass×direction 下的受控结果。
6. **正负不对称主要在大高度差出现。** `|delta_h|<=20 km` 时正负 pooled accept fraction 差的绝对值不超过 `0.03`；`+50 km` 比 `-50 km` 高 `0.0892`，`+100 km` 比 `-100 km` 高 `0.1025`。signed `delta_h` 与总体 accept fraction 的 Spearman 仅 `0.052`，因此不应概括成统一的“升高比降低更危险”，只能报告本次大幅度正向条件较高。
7. **reference subtraction 只在精确方向可比时执行。** 840 个非零 current geometry 中 779 个能找到同 target/pass/exact-direction 的 `delta_h=0` reference，61 个因重新选择方向而不强行相减。reference 的 median raw/post-bk/direction-sensitivity 分别为 `0.109 Hz / 0.0313 Hz / 0.0125 Hz/km`。

本报告不提供统一安全高度，不把 synthetic B 称为真实 Starlink 轨道，也不把描述相关写成高度的普遍因果律。
